# Nossa Vida Financeira

Protótipo de aplicativo web instalável (PWA), desenhado para funcionar no computador, iPhone e tablet Android.

Nesta primeira etapa, os lançamentos ficam no navegador do aparelho para permitir testar a experiência. A base compartilhada já está descrita na pasta supabase; ela será conectada depois de criado o projeto privado no Supabase.

Cada pessoa tem seu próprio login e seus próprios dados. A relação compartilhada entre duas pessoas é uma possibilidade futura, mas está desativada nesta versão.

O app já possui a seção Planejar, onde receitas mensais e despesas fixas podem ser cadastradas e entram nos cálculos do mês.

Para abrir localmente, sirva esta pasta por um servidor web simples e acesse o endereço no navegador.
